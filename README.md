# Urano Acid · Cyber-Brutalist Presentation

Plantilla instalable para **Urano Desktop** basada en el **Template SDK 2**.

Una presentación de alto impacto inspirada en la cultura **Cyber-Brutalista** y **Acid Graphics**: fondos en negro absoluto, acentos verde ácido neón (`#A3FF00`), tipografía monospace táctica, bordes duros y micro-interacciones mecánicas.

---

## Características

* **Navegación Táctica:** Logotipo brutalista `[U]` en bloque verde neón, accesos monospace y selector de módulos integrado.
* **Cabecera de Estado:** Indicadores estilo terminal (`SYS_STATUS: ONLINE`, `ACID PROTOCOL v1.0`), botones con bordes sólidos y atajos rápidos.
* **Historial de Registros:** Lista de conversaciones tratadas como bitácoras de transmisión técnica (`// CONVERSATION_LOGS`), con acentos de sesión activa y buscador reactivo.
* **Bienvenida de Alto Impacto:** Titular gigante `IA SOBRE IA` con efecto de etiqueta/sticker rotada, cinta ticker continua (`⚡ URANO ACID ENGINE ⚡`) y tarjetas de agentes con sombras desplazadas duras.
* **Extra Panel: "Prompt & Snippet Forge":** Taller interactivo de prompts de ingeniería de sistemas, seguridad ofensiva, DevOps y workflows agenticos.

---

## Desarrollo local con Dev Link

1. Abre **Urano Desktop**.
2. Ve a **Mi entorno → Plantillas → DEV TOOLS → Vincular carpeta**.
3. Selecciona la carpeta `UranoDesktop-plugins/urano-acid`.
4. Para compilar cambios en caliente:
   ```bash
   npm run watch
   ```
5. Para validar el paquete:
   ```bash
   npm test
   ```
6. Para exportar el archivo ZIP listo para distribución:
   ```bash
   npm run pack
   ```
